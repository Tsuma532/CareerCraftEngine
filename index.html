Help & privacy

How to use CareerCraft Pro

  1. Upload your CV, check the extracted text, and save it.
  2. Paste the full opportunity text. Add a URL as a reference; if the page is public, you can open it and copy the text here.
  3. Select the required documents and generate drafts.
  4. Paste application form questions and create a worksheet or AI prompt.
  5. Review every detail, word limit, required attachment, and claim before submitting.

Current prototype limitations

  • PDF/DOCX extraction may require an internet connection and may not preserve tables, columns, or scanned text perfectly.
  • Website links cannot reliably be read automatically by this standalone file because many sites block browser access, require sign-in, or restrict automated access.
  • It cannot access private Google Docs unless you copy their contents, nor log into or submit applications on your behalf.
  • The built-in generator uses templates. AI-assisted writing requires using the generated prompt with an AI assistant or connecting a secure AI API/backend.

Privacy

Your CV text is saved in browser local storage on this device only when you choose to save it. Do not use a shared device for sensitive information. Clearing browser storage may erase the saved CV. This file does not transmit your CV to a server.
